# OpenCMR2 VR v0.1.0-alpha.1

First public experimental release for **Meta Quest 3 standalone** and
**Windows x64 PCVR / OpenXR**.

Built on [pablocpas/OpenCMR2](https://github.com/pablocpas/OpenCMR2) and
[pablocpas/CMR2Decomp](https://github.com/pablocpas/CMR2Decomp). Credit belongs to
the original projects and their contributors for the game decompilation and
native SDL port.

**You need your own installed PC copy of Colin McRae Rally 2.0. No original game
files are included.**

## Downloads

- **Quest 3:** `OpenCMR2-VR-Quest-arm64-v0.1.0-alpha.1.apk` — signed standalone APK.
- **Windows PCVR:** `OpenCMR2-VR-PCVR-Windows-x64-v0.1.0-alpha.1.zip` — extract and
  start with `Start-PCVR.cmd` after connecting your OpenXR headset.
- **Complete source:** `OpenCMR2-VR-Source-v0.1.0-alpha.1.tar.gz` — project sources,
  pinned SDL/OpenXR/glslang sources, notices and build instructions.
- **Checksums:** `SHA256SUMS.txt`.

[Read the English installation guide](https://github.com/DR-89/opencmr2-vr/blob/main/README.md#install-on-quest-3).
For Quest, install the APK, ZIP your complete installed PC game, copy that ZIP
to the headset's Download folder, then use **Select game data ZIP → Import
complete → Start game**. PCVR finds common installed game locations automatically
or asks you to select the folder once.

## Included

- Native stereo VR, head tracking and seated recentering.
- Quest Touch controls and the SDL USB-gamepad input bridge.
- **A = shift up / confirm; B = shift down; right stick click = pause / back.**
- English Quest setup with validated ZIP import, storage checks, cancellation
  and recovery. Replacement imports preserve saves.
- Automatic Windows installation discovery and a double-click PCVR launcher.
- A game-data-free VR diagnostic scene and runtime license notices.
- Fix for the Quest launch issue that could play sound while showing only
  passthrough: OpenXR now runs in the main app process, with setup in `:setup`.
- Initialization fix for the pinned SDL OpenXR API-layer property structures.

## Validation and limitations

Windows and Quest release builds succeed. All **20 native tests** and **14 Java
importer tests** pass; Android lint reports zero errors and 43 warnings. APK
signature/alignment and the extracted Windows package's 30-frame Vulkan
diagnostic are checked. Downloads were inspected for game assets and credentials.

Quest gameplay, the ZIP import flow and Windows PCVR through Virtual Desktop
have been confirmed in hardware testing. The normal Unknown Sources launch was
retested after the process fix and picture/sound were confirmed. These user
checks used development APKs; the signed public APK has not replaced the private
debug installation on the test headset.

This is **not a finished or fully validated port**. Observed Quest race rates
are approximately **46–55 FPS**; the 72 FPS diagnostic figure is not gameplay
performance. Physical USB gamepads on Quest, other Quest models/OpenXR headsets,
extended save/load testing, sleep/wake and VR multiplayer remain unvalidated.

Private debug builds use a different signing key. **Back up saves before
migrating** to this public APK; uninstalling removes app data and requires
another game-data import. Future public updates will use the same release key.

Report reproducible VR issues in this repository, without attaching game files.
